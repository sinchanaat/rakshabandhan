# Spandu Birthday Website 🎂

A completely redesigned best-friend birthday website for Spandu.

Birthday: **22 August 2026**

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, `spandu-memories.webp` and this README to a public repository. Enable GitHub Pages from `main` / root.

Optional: add `birthday-music.mp3` to enable the music button.
